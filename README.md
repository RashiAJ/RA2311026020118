# RA2311026020118

Campus notification platform: **logging middleware**, **Stage 1** CLI (`notification_app_be`), **web UI** (`notification_app_fe`), and **Notification_System_Design.md**.

| Area | Folder | Run |
|------|--------|-----|
| Backend CLI | `notification_app_be` | `npm run register` → `npm run auth` → `npm run stage1` |
| Frontend | `notification_app_fe` | `npm install` → `npm run dev` (uses Vite proxy to the evaluation API) |

Details: `notification_app_be/README.md`, `notification_app_fe/README.md`.
